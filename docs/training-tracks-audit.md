# Экскурсия: треки, действия, сборка и получение

Проверка от 2026-09-14. Область: 20 шагов четырёх тем; 19 относятся к `TracksScreen`, один открывает `/photos` и относится к аудиту другой поверхности. Общий каталог сейчас содержит 56 шагов. Ниже отдельно отмечены проверка исходников, выполнение настоящих UI-действий и ограничения.

Тестовый стенд использует обычные `TracksScreen`, `TrainingTourOverlay`, реальную карту `trainingTourSteps`, providers и сервис сборок. Данные поставляет отдельный `AssemblyTrainingSession`: два складских трека, один ожидающий поступления и созданная локально сборка. HTTP transport целиком локальный; токен аккаунта и общий кэш отключены. Форма возврата в проверке не отправляется; существующая сборка для проверки доставки создаётся только в локальном transport.

## Исправленные состояния

- `tracks.view.switch-to-singles` и `tracks.view.switch-to-groups` существуют только когда соответствующее представление ещё не выбрано. Пустой список не заставляет экскурсию повторно указывать на уже выбранный переключатель.
- `track.sheet.dismiss-handle` соответствует существующей ручке 42×25. На мобильном окно закрывается жестом вниз, в desktop side sheet — вправо. Новая кнопка закрытия не добавлялась.
- `assembly.required.goods-description`, `assembly.required.places`, `assembly.required.packaging` и `assembly.required.insurance-amount` используют существующие условия заполненности формы. Это точные поля/варианты, а не секции формы. После ввода prerequisite исчезает, и подсветка переходит к активному `assembly.wizard.ready.N`.
- Для обратной навигации сохранены точные `assembly.wizard.back-to-tariff` и `assembly.wizard.back-to-packaging`.

## Проверка

Команда:

```sh
flutter test --no-pub test/features/training/training_tracks_tour_integration_test.dart
```

Тесты сравнивают реальные координаты рамки CustomPainter с RenderBox требуемого элемента, включая описание товара, страховую сумму, количество мест, упаковку, ручку закрытия и кнопку переноса. Проверка не ограничивается наличием anchor в дереве.

Свежий результат: **5 тестов прошли**, включая геометрические assertions фактической рамки. Лог запуска: `/tmp/tracks-ordinary-tour-tests.log`, финальная строка `00:18 +5: All tests passed!`.

## Границы доказательств

- Сеть production не использовалась. Тесты подтверждают взаимодействие UI с изолированными данными, но не актуальные состояния реальных клиентов.
- В большом виртуализированном `SliverList` подходящий трек может быть ещё не построен. Anchor появится после прокрутки/сужения списка. Автоматический поиск по незагруженным страницам здесь не добавлен; экскурсия объясняет зависимость от данных, поиска и фильтров и допускает пропуск.
- Отсутствие подходящих треков, сборок или доступного действия не подменяется рамкой всей карточки. Для переноса сам обработчик дополнительно требует другой код клиента; открытие переноса при единственном коде в этом тестовом стенде не проверялось.
- `/photos`, видеофайлы и успешные реальные операции возврата/переноса вне области этих тестов.
