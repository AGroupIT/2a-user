## Запуск preview для чтения инструкций

Из `2a-user`:

```sh
flutter run -d web-server --web-hostname 127.0.0.1 --web-port 8094 --no-pub -t lib/training_preview.dart
```

Открыть `http://127.0.0.1:8094`. Для китайской версии добавить `--dart-define=TRAINING_LOCALE=zh`.

В текущей версии standalone preview показывает только чтение: без callback запуска настоящей практики её кнопка скрыта, отдельная историческая форма не открывается. Для практики в приложении используется `/training/assembly`.

Standalone preview не запускает авторизацию, API, push, аналитику и старый деморежим. Использует нейтральную палитру; в авторизованном приложении тема берётся из существующего оформления компании.
