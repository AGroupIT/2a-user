# SEO-задачи для 2a-logistic.ru

## Принципы

1. **Работа поблочно.** Никогда не бери весь сайт целиком. Получил ТЗ — выбери один блок, предложи улучшения по нему, дождись одобрения, переходи к следующему.

2. **Off-limits блоки (не трогать, если не просят явно):**
   - «Отзывы»
   - «Цены» / «Тарифы»

3. **Формат предложений.** Для каждого блока давай:
   - Текущее состояние (если знаешь)
   - 2-3 варианта улучшения
   - Аргументы «почему» (SEO-логика, UX-логика)
   - Риски / трейд-оффы

4. **Сохраняй решения в Vault.** После утверждения предложи:
   ```
   Записать это решение в Vault/40-SEO/YYYY-MM-DD-<block-name>.md?
   ```
   Шаблон записи — в `Vault/40-SEO/README.md`.

## SEO-специфика для 2a-logistic

- Ниша: **логистика** (грузоперевозки).
- Основная аудитория: B2B и B2C клиенты, ищущие перевозку.
- Ключевые запросы: «грузоперевозки», «доставка», «логистика», региональные вариации.

## Антипаттерны, которых избегать

- ❌ Переспам ключевыми словами в H1/H2
- ❌ Дублирование title и H1
- ❌ Meta description как «копия первого абзаца»
- ❌ Стены текста без структуры
- ❌ Общие фразы («лучшая компания», «большой опыт») — они ничего не говорят SEO-роботу

## Что делать в реальности

- Заголовки — конкретные, с цифрами/регионами/сроками
- Meta description — 150-160 символов, с CTA
- Структура H1 → H2 → H3 — логичная
- Alt-атрибуты на изображениях
- Schema.org markup для услуг/компании (если есть доступ)
