Клиентское приложение Flutter для заказчиков 2A-Logistic.

Контекст:
- Использует общие блоки из 2a-shared
- UX должен быть максимально простым — это конечные клиенты
- Целевая аудитория: отправители грузов

При работе здесь:
- Особое внимание к валидации форм и обработке ошибок сети
- Flutter state management — см. правила в глобальных инструкциях
- Команды: flutter analyze, flutter test, dart format
